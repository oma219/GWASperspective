# :dna: GWASperspective

This repo contains the analysis code for the **GWAS perspective paper** along with the **final plotting scripts** for each figure included in the paper.

Here is high-level overview of the folder structure:
```sh
# all final plots/code/data used in paper and supplementary
all_plotting/

# example used for figure 1c
fig1_example_gwas/

# raw data for gwas data limitations
fig2_data_limitations/

# analysis of ld dropout across gwas/dropout simulation
fig3_ld_dropout/

# colocalization and functional fine-mapping scripts
fig4_coloc_and_func/

# applying DL models to GWAS loci
fig5_deep_learning/
```
